## Run a check

Install Codependence in the project and run it from the directory that contains your policy.

```sh
npm install --save-dev codependence
npx codependence init config
npx codependence
```

> [!NOTE]
> A check exits with status `1` when a dependency needs an update. Run `--update --dryRun` to see the proposed edits.

```sh
npx codependence --update --dryRun
npx codependence --update
```

## Configuration options

Put a `.codependencerc` at the repository root. In this example, the CLI checks the lodash declaration in the web app’s manifest against `4.17.21`.

```json title=".codependencerc"
{
  "config": {
    "web": {
      "path": "packages/web/package.json",
      "manager": "npm",
      "codependencies": [{ "lodash": "4.17.21" }]
    }
  }
}
```

| Field | What it controls |
| --- | --- |
| `path`, `manager` | The manifest path relative to the config file and the tool that owns it. Give each manifest a separate entry under `config`. |
| `codependencies` | A name such as `"lodash"` looks up a version. An object such as `{ "lodash": "4.17.21" }` sets the required declaration. Node policies also accept ranges and trailing wildcards such as `"@team/*"`. |
| `mode` | `verbose` checks the listed packages. `precise` holds them back and checks the rest. Existing configs can use `permissive: true` for precise mode. |
| `level` | Allow `patch`, `minor`, or `major` updates. The default is `major`. |
| `lockfile` | Set `true` to require a standard lockfile, or supply a relative path or list of paths. Each target can override the root setting. |
| `rootDir`, `ignore` | Set the search directory and exclude files that match the listed globs. |

For glob-based selection, use a `targets` array with a `manager` and `files` on each target. Choose one root form per config file. Existing projects can also keep a policy under `codependence` in `package.json`.

### Supported managers

Use `npm`, `pnpm`, `yarn`, or `bun` for Node manifests. Experimental managers include `pip`, `pipenv`, `poetry`, `uv`, `conda`, `go`, `rust`, `docker`, `github-actions`, `circleci`, `helm`, `kubernetes`, `kustomize`, and `terraform`. For CircleCI, Helm, Kubernetes, Kustomize, and Terraform, give each dependency an explicit version in `verbose` mode.
