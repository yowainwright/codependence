## Why use Codependence?

For example, you can schedule Go updates for Fridays and review Docker base image updates in a separate pull request.

- Define which packages must stay current or pinned
- Configure multiple dependency managers in one `.codependencerc`
- Fail a CI check when a package needs an update
- Update only listed packages, or update everything except listed packages
- Choose different packages to update in each workspace
- Run locally, in npm scripts, in GitHub Actions, or through the Node API
- [Open or refresh an update pull request with GitHub Actions.](/docs/github-action/)
