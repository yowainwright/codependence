## Synopsis

Run `codependence` to see which dependencies need an update. It reads the list of files and packages to check from `.codependencerc`.

Use `codependence --update --dryRun` to preview the edits, then `codependence --update` to write them. To review updates in pull requests, [set up the GitHub Action](/docs/github-action/).
