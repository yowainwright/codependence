## Check a manifest from a script

Suppose your project requires lodash `4.17.21` but its manifest still declares `4.17.20`. Start with this file in an empty directory.

```json title="package.json"
{
  "name": "policy-example",
  "private": true,
  "dependencies": { "lodash": "4.17.20" }
}
```

Run `npm install --save-dev codependence`. Save the following script beside `package.json` and run `node check.mjs` from that directory. The CLI reads repository configuration. When calling the Node API, pass the files and policy directly.

```javascript title="check.mjs"
import { checkFiles } from "codependence";

try {
  await checkFiles({
    files: ["package.json"],
    codependencies: [{ lodash: "4.17.21" }],
  });
} catch (error) {
  process.stderr.write(String(error) + "\n");
  process.exitCode = 1;
}
```

The version mismatch rejects the promise. The script exits with status `1` and leaves `package.json` untouched. Once the declaration matches, the check resolves.

## Inspect the proposed edits

For a report, pass `format: "json"`. In Node this collects JavaScript objects. Your script chooses how to display them and what exit status to return.

```javascript title="report.mjs"
import { checkFiles } from "codependence";

const diffs = await checkFiles({
  files: ["package.json"],
  codependencies: [{ lodash: "4.17.21" }],
  format: "json",
});

for (const diff of diffs ?? []) {
  if (diff.willUpdate) {
    process.stdout.write(`${diff.package}: ${diff.current} -> ${diff.latest}\n`);
  }
}
```

Run `node report.mjs` before applying the update. It prints:

```text
lodash: 4.17.20 -> 4.17.21
```

Each `VersionDiff` includes the package name, its current declaration, the target version (`latest`), whether the package is listed in the policy (`isPinned`), and whether it qualifies for an edit (`willUpdate`). The return type is `Promise<VersionDiff[] | void>`. A formatted call can still reject, for example when a required lockfile is missing.

## Apply the edit

```javascript title="update.mjs"
import { checkFiles } from "codependence";

await checkFiles({
  files: ["package.json"],
  codependencies: [{ lodash: "4.17.21" }],
  update: true,
});
```

Run `node update.mjs`, then `node check.mjs` again. The declaration now reads `"lodash": "4.17.21"` and the check passes. Run `npm install` to refresh the lockfile and installed packages.
