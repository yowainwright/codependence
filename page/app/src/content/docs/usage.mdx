## Catch a mismatched package version

Start in an empty directory with these two files. The app declares lodash `4.17.20`, but the project requires `4.17.21`.

```json title="package.json"
{
  "name": "web-app",
  "private": true,
  "dependencies": { "lodash": "4.17.20" }
}
```

<CodeDemo label="Check the web app" steps={[
  { line: 4, label: "Manifest", note: "This path selects the package.json beside the config file." },
  { line: 6, label: "Required version", note: "The check compares the declared lodash version with 4.17.21. Other packages are outside this rule." },
]}>

```json title=".codependencerc"
{
  "config": {
    "web": {
      "path": "package.json",
      "manager": "npm",
      "codependencies": [{ "lodash": "4.17.21" }]
    }
  }
}
```

</CodeDemo>

Run the check from that directory. The output lists lodash with current version `4.17.20` and available version `4.17.21`. The exit status is `1`.

```sh
npx codependence
```

Apply the update, then run the same check again.

```sh
npx codependence --update
npx codependence
```

The second check exits with status `0`. Codependence updates lodash and fills in the empty dependency sections.

<CodeDemo label="Inspect the package.json update" steps={[
  { line: 5, label: "Lodash version", note: "The manifest now declares the exact version required by the policy." },
]}>

```diff title="package.json"
   "name": "web-app",
   "private": true,
-  "dependencies": { "lodash": "4.17.20" }
+  "dependencies": {
+    "lodash": "4.17.21"
+  },
+  "devDependencies": {},
+  "peerDependencies": {},
+  "optionalDependencies": {}
```

</CodeDemo>

## Update a Docker base image

In a second directory, create a Dockerfile that takes its Alpine version from a build argument.

```text title="Dockerfile"
ARG ALPINE_VERSION=3.19
FROM alpine:${ALPINE_VERSION}
RUN cat /etc/alpine-release
```

Save this policy alongside it. The `docker` manager checks the base image declaration. You can run the example without building an image.

```json title=".codependencerc"
{
  "config": {
    "container": {
      "path": "Dockerfile",
      "manager": "docker",
      "codependencies": [{ "alpine": "3.20" }]
    }
  }
}
```

Preview the change. The CLI reports `3.19` and `3.20` and leaves the Dockerfile untouched.

```sh
npx codependence --target docker --update --dryRun
```

Apply it and check the result.

```sh
npx codependence --target docker --update
npx codependence --target docker
```

<CodeDemo label="Inspect the updated Dockerfile" steps={[
  { line: 2, label: "Updated tag", note: "The FROM instruction reads this build argument. The next build uses Alpine 3.20." },
]}>

```diff title="Dockerfile"
-ARG ALPINE_VERSION=3.19
+ARG ALPINE_VERSION=3.20
 FROM alpine:${ALPINE_VERSION}
 RUN cat /etc/alpine-release
```

</CodeDemo>
