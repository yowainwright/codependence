## Check a web app and a Go service

Give each manifest a name in the root `.codependencerc`. Here the web app uses pnpm and the API uses Go.

<CodeDemo label="Check two manifests" steps={[
  { line: 4, label: "Web app", note: "The web entry checks the package.json inside packages/web." },
  { line: 9, label: "Go service", note: "The api entry reads go.mod in services/api. Both paths start at the directory containing this config." },
]}>

```json title=".codependencerc"
{
  "config": {
    "web": {
      "path": "packages/web/package.json",
      "manager": "pnpm",
      "mode": "precise"
    },
    "api": {
      "path": "services/api/go.mod",
      "manager": "go",
      "mode": "precise"
    }
  }
}
```

</CodeDemo>

Run `codependence` to check both manifests. To preview just the Go updates, run:

```sh
codependence --target go --update --dryRun
```

## One-off CLI check

```sh
codependence --codependencies lodash fs-extra
```

## Wildcard patterns (latest for all matches)

```sh
codependence --codependencies '@foo/*' --update
```

## Permissive mode (update all except specific)

```sh
codependence --codependencies 'react' 'lodash' --permissive --update
```

## Legacy flat config

`.codependencerc`:

```json
{
  "permissive": true,
  "codependencies": ["react", "@types/node"]
}
```

Run:

```sh
codependence --update
```

## Preview changes without modifying files

```sh
codependence --update --dryRun
```

## Output as JSON for CI/CD

```sh
codependence --format json
```

## Save a report from a failing check

Suppose the app declares lodash `4.17.20` and its policy requires `4.17.21`. Save the check result before updating.

```sh
codependence --format json --outputFile dependency-report.json
```

The command exits with status `1`. This excerpt from `dependency-report.json` shows what failed.

<CodeDemo label="Read the check result" steps={[

  { line: 6, label: "Outdated packages", note: "One dependency in this example needs an update: lodash." },

```json title="dependency-report.json (excerpt)"

  "summary": {

    "outdated": 1,
    "upToDate": 0
  }
}
```

</CodeDemo>
